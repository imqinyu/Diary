# 一款为 macOS 打造的简单日记软件 

系统要求：macOS 15.0 Sequoia

软件现在还没有图标 如果你有不错的想法 欢迎和我交流

**重要：软件还处在不断完善的阶段 如果你真的想用 请勤使用备份功能**

## 软件特色

- 遵循苹果 HIG

- 无法修改过去：一旦过了你写的那天 日记内容将无法修改 即使删除 也会留下标签 日期等内容 如同真实日记本被撕去了一页

- 后备隐藏系统：密码输入入口在搜索框 在未解锁前 相关功能 包括设置会全部隐藏 旁人甚至无法知晓有日记隐藏功能 有效防止史塔西和盖世太保偷窥 另外可选双重保险 额外验证触控 ID 访问会留下日志 随时可以核对记录

- 体积小：仅 6mb 同时支持英特尔和 M 系列芯片的 mac

- 文件按 `entries/年/月/日/` 归档，例如 `entries/2026/11/16/2026-11-16-1.md`；当天图片放在 `assets/` 内，按篇分开。现有文件会自动迁移，加密日记在解锁后迁移。

- 支持用 ⌘V 粘贴截图、图片和从访达复制的图片文件，图片保存到本地 assets，正文使用相对路径。

- “类型”中可筛选补写日记，列表和详情显示补写标记。旧日记也会根据补写期限与最后编辑日期识别。

- 空白日记直接删除；有正文、图片或自定义标题时仍需确认。

旧版备份位置需在备份设置中重新选择一次，以保存目录访问授权。
