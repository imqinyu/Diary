# 一款为 macOS 打造的简单日记软件 

系统要求：macOS 15.0 Sequoia

软件现在还没有图标 如果你有不错的想法 欢迎和我交流

**重要：软件还处在不断完善的阶段 如果你真的想用 请勤使用备份功能**

## 软件特色

- 遵循苹果 HIG

- 无法修改过去：一旦过了你写的那天 日记内容将无法修改 即使删除 也会留下标签 日期等内容 如同真实日记本被撕去了一页

- 后备隐藏系统：密码输入入口在搜索框 在未解锁前 相关功能 包括设置会全部隐藏 旁人甚至无法知晓有日记隐藏功能 有效防止史塔西和盖世太保偷窥 另外可选双重保险 额外验证触控 ID 访问会留下日志 随时可以核对记录

- 体积小：仅 6mb 同时支持英特尔和 M 系列芯片的 mac

- 文件按 `entries/年/月/日/` 归档，例如 `entries/2026/11/16/2026-11-16-1.md`；当天图片放在 `assets/` 内，按篇分开。现有文件会自动迁移，加密日记在解锁后迁移。

- 支持 GitHub 同步，可选择公开仓库（不推荐）或私有仓库

## GitHub 私有仓库同步

在「设置 → 同步」中点击「登录 GitHub」，打开授权页并输入软件显示的验证码。登录后选择有写入权限的私有仓库，或直接创建一个，再点击「连接并同步」。其他 Mac 使用同一账号和仓库即可同步，无需安装 Git 或 Xcode。

软件使用 GitHub Device Flow；内置的 OAuth Client ID 是公开应用标识，不是密钥。访问授权只保存在本机 macOS 钥匙串，不写入日记、备份或仓库。

- 只同步 `entries/` 中的 Markdown 和图片，保留仓库中的其他文件。每次变更生成 Git 提交，删除也会传播；历史文件仍可从 GitHub 提交记录恢复。
- 启动时检查，保存后等待 30 秒同步，运行期间每 5 分钟检查更新。也可点击「立即同步」。离线时照常保存到本机，联网后重试。
- 不同文件的修改自动合并；同一文件双方修改会暂停同步并保留双方副本。在设置中比较并选择本机或 GitHub 版本。冲突原文件保存在本机 Application Support，不上传到仓库。
- 隐私日记的正文与图片一起以密文同步，标题、日期、标签等元数据仍为明文。图片保留原始字节，以 `data:image/...;base64,...` 内嵌 Markdown，再整体使用 AES-GCM 加密；Base64 本身仅是编码。Android 和 macOS 使用同一格式，其他设备需设置相同的隐私密码才能解密。
- 封存日记也可以隐藏与取消隐藏，正文仍保持封存。解锁时自动迁移旧隐私图片，成功后移除独占的明文 assets；被公开日记引用的共享图片保留。缺失图片会阻止迁移并保留原文件。密码与验证记录不会上传；旧版密文首次同步前需解锁一次，补齐公开的加密盐参数。
- 旧 ZIP 备份与 Git 提交历史中的明文图片不会自动清除，新格式只保护迁移后的当前文件。
- 单文件上限为 90 MiB。更换本机日记存放位置后，需要重新选择同步仓库。

GitHub 同步保留历史版本，本机备份仍可独立使用。

图片协议、旧条目隐藏、编辑器往返、相册、换密码回滚及 Android 密文互通由 `Tests/run-private-image-checks.sh` 在临时目录验证。相册缩略图在后台解码，内存缓存限制为 64 项、32 MiB，并在锁定时清空。
